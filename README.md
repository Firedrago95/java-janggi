# java-janggi

장기 미션 저장소

## 기능 구현 목록

### 위치
 - [x]10 X 9 범위를 벗어난 값인지 검증한다

### 기물
 - 이동 가능한 목적지인지 검증한다.
 - 자신이 갈 수 있는 경로를 반환한다.
   - 포 : 기물 하나를 뛰어넘어 이동한다. 포를 뛰어넘거나, 잡을 수 없고 두개이상의 기물을 넘을 수 없다.
         (궁성 내에서 대각 이동이 가능하다)
   - 차 : 상 하 좌 우 칸수 제한없이 이동할 수 있다.
         (궁성 내에서 대각 이동이 가능하다)
   - 마 : 상 하 좌 우 한칸 + 대각선 한칸 총 8가지 경로로 이동 할 수 있다.
   - 상 : 상 하 좌 우 한칸 + 대각선 두칸 총 8가지 경로로 이동 할 수 있다.
   - 사 : 상 하 좌 우 한칸 + 궁성 대각선 궁성 내에서만 이동 할 수 있다.
   - 궁 : 상 하 좌 우 한칸 + 궁성 대각선 궁성 내에서만 이동 할 수 있다.
   - 졸 : 직진, 좌 우 한칸 진영에 따라 직진 방향이 달라진다.
         (궁성 내에서 대각 이동이 가능하다)

### 보드
 - 경로상의 기물을 탐색한다.
 - 기물의 위치를 변경하여 이동시킨다.
